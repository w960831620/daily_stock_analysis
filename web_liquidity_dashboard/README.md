# US Liquidity Web Dashboard

This is a browser-based web dashboard.

Path:

- `docs/us-liquidity/index.html`

Features:

- Auto fetches FRED data in the browser.
- Auto fetches Yahoo Finance market data in the browser.
- Refreshes every 30 minutes while the page is open.
- Shows liquidity score, traffic light, SPY/QQQ/BTC trend, VIX, NFCI, and Net Liquidity vs SPY chart.
